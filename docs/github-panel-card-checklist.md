# GitHub panel card checklist

This draft PR is sample data for dogfooding the GitHub panel.

- Open GitHub from the side-panel launcher and check that this PR appears.
- Check the draft badge, PR number, title, branch names, and update date.
- Click the title and verify that it opens this PR on GitHub.
- Resize the panel and check long-title wrapping and branch truncation.
- Refresh and confirm that cards stay visible while the request runs.

Close this draft when no longer needed; it does not need to be merged.
